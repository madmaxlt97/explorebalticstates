# 🌍 Explore Baltic States — Travel Guide Platform (Prototype)

A content-driven web application dedicated to providing comprehensive travel guides, hotel reviews, and restaurant recommendations across Lithuania, Latvia, and Estonia.

⚠️ **Project Status:** *Early prototype / Draft stage (Core logic and data structure design).*

## 🛠 Tech Stack

* **Frontend:** React (Single Page Application)
* **Build Tool:** Vite
* **Language:** TypeScript

## 🎯 Current Focus & Architecture
At this stage, the project serves as a foundational draft. The current focus is entirely on:
* Setting up the core React component structure.
* Designing the data layouts for regional travel information, historical summaries, and curated lists.
* Ensuring clean TypeScript typing for the platform's content.

## 🗺 Future Roadmap (The Next.js & Tailwind Migration)
This repository is a stepping stone for a much larger, production-grade application. Once the core data structure is ready, the project will undergo a complete transformation:
* [ ] **Styling Overhaul:** Implementing a modern, fully responsive mobile-first UI using **Tailwind CSS**.
* [ ] **Architectural Upgrade:** Migrating the entire codebase to **Next.js (App Router)** to unlock Server-Side Rendering (SSR) for seamless search engine indexing (SEO).
* [ ] **Performance Optimization:** Leveraging Next.js native features (`next/image`, font optimization) to ensure top-tier Core Web Vitals scores.

## 💻 Getting Started

### Installation
1. Clone the repository:
```bash
   git clone [https://github.com/madmaxlt97/explorebalticstates.git](https://github.com/madmaxlt97/explorebalticstates.git)
```
2. Install dependencies:
```bash
  npm install
```
3. Run the development server:
```bash
  npm run dev
```

Open http://localhost:5173 with your browser to see the result.
